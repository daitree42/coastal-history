**【故事层】**

1928年——南京——国民政府的军队——完成了「北伐」——统一了中国——中国——在名义上——终于——又有了——一个——能够——号令全国的政府。

6月28日——国民政府——发布了一道——简短的命令：「改直隶省为河北省——北京——改名为——北平。」

「京」——意思是——首都。「平」——意思是——平定——平和——平安。「北京」——变成「北平」——就意味着——这座——做了五百多年首都的城市——不再是——中国的——政治中心了。

消息传到北京——北京城里的——反应——很复杂。一些人——感到遗憾——「做了五百年首都——说改就改了」——一些人——觉得——松了一口气——「终于——不用——再被——那些——当官的——占据了。」还有些人——无所谓——「改名——又不改命——老百姓——不还是——一样过日子？」

最感到失落的——是——北京的那些——清朝遗老——和——北洋政府的官员们。南京——成了——新的首都——权力中心——移到了南方——他们——在北京——再也——找不到——可以——领取俸禄的——差事了。很多旗人——在清朝灭亡后——本来就——已经——失去了——经济来源——改名——对他们来说——又——是一次——身份上的——剥夺。

但——北京——仍然是——北京——不管它——叫做——什么。

**【历史背景层】**

**北京的名字——一部浓缩的政治史**

北京——在历史上——改过——很多次名字。每一次改名——都对应着——一次——重大的——政治变迁。

| 时期 | 名字 | 含义 |
|------|------|------|
| 周-隋唐 | 蓟/幽州 | 边疆城市——而非首都 |
| 辽 | 南京 | 辽国陪都——草原帝国的南方门户 |
| 金 | 中都 | 正式首都——「居天下之中」 |
| 元 | 大都 | 蒙古帝国的首都——「汗八里」 |
| 明(前期) | 北平 | 明朝初期——失去首都地位——改为「北方平定」 |
| 明(1403年后) | 北京 | 永乐迁都——「北方之京」 |
| 清 | 北京 | 继承明朝名称——延续不变 |
| 1912-1928 | 北京 | 民国初期——北洋政府在此——仍是名义上的首都 |
| 1928-1937 | 北平 | 国民政府定都南京——北京降格为「北平」 |
| 1937-1945 | 北京 | 日本占领下——改回「北京」——意为「华北的首都」 |
| 1945-1949 | 北平 | 抗战胜利后——恢复「北平」名称 |
| 1949年至今 | 北京 | 中华人民共和国成立——重新定都于此——恢复「北京」名称 |

每一次改名——都是一种——政治表态。叫「北京」——意味着——这座城市——是首都。叫「北平」——意味着——它——不是首都。

**1928-1937——作为「北平」的十年**

1928年至1937年——是北京的——「降格时期」。这座城市——从——帝国的首都——变成了——一个——普通的——北方城市。

降格——带来了一些——负面影响：中央政府机构——迁往南京——北京——失去了——数以万计的官员——和——附属人口。北京的——商业——开始——萎缩——因为——政治中心——带走了——大量的——消费需求。许多——曾经——依赖朝廷和官员——维生的——商人——手工业者——和——服务业者——失去了——收入来源。

但——降格——也——带来——一些——积极的变化。北京——不再是——权力斗争的——中心——它——变得——平静了。北京——的——文化——和——学术——在——这段时期——却——异常繁荣——因为——很多——知识分子——选择——留在北京——而不是——去南京——做官——他们——在北京的大学里——教书——写作——做研究。

北平——的——大学教育——在——这一时期——达到了——中国近代史上的——一个高峰。北京大学——清华大学——燕京大学——辅仁大学——都——在——这一时期——做出了——重要——的——学术贡献。北平——成为了——中国——最重要的——学术——和——文化中心——虽然——它——不再是——政治中心了。

**【深挖层】**

**「京」和「平」——名与实的纠缠**

「北京」——和——「北平」——这两个名字——在二十世纪上半叶——反复更替——它的背后——是中国——政治中心的——南北之争。

从明朝开始——北京——作为中国的政治中心——长达五百多年。但——在二十世纪初——很多人——认为——北京——太偏北了——离——中国的经济中心——江南——太远——离——世界的海洋通道——也太远。如果——中国——要——成为一个——面向世界的——现代国家——它的首都——应该——迁到——更靠南的——地方——最好是——南京——或——上海。

迁都——在辛亥革命后——被——很多人——认真——讨论过。孙中山——主张定都南京——袁世凯——坚持定都北京。最后——袁世凯——赢了——北京——在民国初期——仍然是首都。但——1927年——国民革命军——北伐——攻占南京——定都的——争论——再次——浮出水面。这一次——是——南京——赢了。

定都南京——不仅仅——是一次——地理上的——转移——更是一次——政治上的——权力转移——从北洋军阀——和——北方士绅——到——南方革命党人——和——江南资本家的——转移。

1949年——中华人民共和国——成立——重新定都北京——是一个——同样具有——强烈政治含义的——选择——标志着——新中国——对——中国——现代历史——中——所有——重大事件——的——继承——从——五四运动——到——抗日战争——从——共产党的诞生——到——新中国的——成立。

**【旅行层】**

**北京·北大红楼（五四大街）**

北京作为「文化中心」的标志性建筑——原北京大学文科大楼——1918年建成——是五四运动的重要策源地——现在是北京新文化运动纪念馆——是理解「北京为什么在降格为北平后——反而文化更繁荣」的关键地点

**北京·清华大学**

中国最顶尖的大学之一——在「北平时代」——清华大学——完成了——从一所留美预备学校——到——综合性大学的——转型——校内的——清华学堂——工字厅——水木清华——和——图书馆——是——民国时期——北平——学术黄金时代——的——代表性——建筑

**北京·正阳门火车站**

民国时期北京（北平）最重要的交通枢纽——也是——北京——从首都——变成——普通城市——的——见证者——南来北往的——旅客——从——这里——进京或离京——1937年——日军——也是——从这里——开进了——北京城
