**【故事层】**

1950年的一个下午，北京，梁思成，站在，东直门附近的城墙根下，和，一位苏联专家，发生了，一次，令他，极其，痛苦的，争执。

梁思成，是中国最杰出的建筑学家，梁启超的儿子，在美国宾夕法尼亚大学，学习建筑，回国后，创办了，东北大学建筑系，和，清华大学建筑系，他对，北京的古建筑，有着，最深刻的，理解和，最深厚的情感。他，刚刚，和，他的妻子，林徽因，一起，完成了，对，北京中轴线，和，故宫建筑群，的，全面的，测绘，和，记录，这是，中国建筑史上，第一份，系统性的，北京古建筑，档案。

梁思成，向，北京市政府，提出的，建议，是，在，北京老城的，西郊，建设，一座，全新的，行政中心，把，政府机关，都，搬到，西郊去，保留，老城的，完整，城墙，城门，牌楼，胡同，和，四合院，把，北京老城，作为一个，整体的，历史文化遗产，保护下来。

他，在，图纸上，画出了，他的，方案，在西郊，复兴门外，规划，一个新的，「行政中心」，呈，十字形，的，街道布局，两侧，分布，政府办公楼，和，公共建筑，而，老城，则，保持原样，以，故宫，为中心，以，中轴线，为脊梁，成为一个，「活的博物馆」。

但，苏联专家，和，大多数，中国城市规划者，认为，梁思成的，方案，不可行。他们的理由，很，实际：在西郊，新建，一座，行政中心，需要，大量的，资金，和时间，而新中国，没有，这个条件。他们主张，利用，旧城，现有的，基础设施，在，老城的基础上，进行，改造，让，北京，从，一座，封建帝都，变成，一座，社会主义的，工业城市。

梁思成，站在，东直门城楼下，他的声音，有些，发抖，他对，苏联专家说，

「你们，现在，看到，的，这些，城墙，城门，和，牌楼，它们，是，中国的，历史，是，独一无二的，将来，你们，会后悔的。」

苏联专家，耸了耸肩，说，

「梁同志，历史，是，向前看的，不是，向后看的。我们，要建设，一座，新北京，不是，保存，一座，旧北京。」

梁思成，后来，在他的，日记里，写道，

「北京，将要，失去，它，最珍贵的东西，而，所有人，都，认为，这是，进步。」

**【历史背景层】**

**梁思成的方案，「新旧分治」**

梁思成的，保护方案，核心，是，「新旧分治」：在西郊，建设，新北京，作为，行政，和，工业中心，在，东郊和南郊，发展，工业区，保留，老城，作为，文化，和，居住区，不进行，大规模的，改造，不拓宽，道路，不拆除，城墙。

这个方案，在，当时的中国，是非常，超前的。它，与，二战后，欧洲，对，历史城市的，保护理念，完全，一致，比如，华沙，在，战后重建，就，采取了，「老城全面修复，新城另址发展」的，模式。但，在1950年代的，中国，这种，理念，不被理解，甚至，被，视为，「资产阶级的，怀旧情绪。」

**北京的改造，旧城成了新城的代价**

最终的，决定，是，在，旧城的基础上，进行，大规模改造，将，北京，从，消费城市，变为，生产城市。

这个决定的，后果，在，接下来的，几十年里，逐渐，显现。北京的，城墙，在，1950至1960年代，被，逐步，拆除，城墙的城砖，被，拉走，用于，建设，防空洞，和，一些，市政工程，护城河，被，填平，修建，地铁一号线。到今天，北京，只有，零星的，几段，城墙，被，保存了下来，包括，东南角楼附近，和，正阳门城楼。

北京的，牌楼，也，被，大量，拆除。原来，北京，有，上百座，牌楼，到，1966年，只剩下，二十多座出，在，交通改造中，被，迁移，或，拆除，剩下的部分，在，文革中，被，红卫兵，砸毁，更多。

北京，在1950至1970年代的，城市改造，将，一座，世界上，保存最完整，的，古代都城，变成了，一座，普通的，现代城市，它的，独特的，城市形态，被，从根本上，改变了。

**【深挖层】**

**梁思成的失败意味着什么？**

梁思成的，失败，不仅仅，是，一个人的，失败，它，代表着，一种，发展理念，在，另一种，更强大的，政治逻辑，面前，的，失败。

在1950年代的，中国，国家建设的，首要目标，是，工业化。一切，都要，为，工业化，和，社会主义改造，服务，包括，城市，规划。北京，作为，社会主义新中国的，首都，应该，展示，新，中国的，力量，和，进步，而不是，被，旧时代的，遗迹，所，束缚。

在这种，政治逻辑下，梁思成的，「保护老城，另建新城」的，方案，被，视为，「保守」，「落后」，和，「不切实际」的。保护城墙，被，理解为，「封建残余思想」，保留胡同，被，理解为，「小资产阶级的情调」，这些，在，1950年代的中国，都是，非常，严肃的，政治指控。

梁思成，在后来的，运动中，受到，批判，他的，保护方案，被，当作，「资产阶级建筑思想」的，典型，受到，公开，批评。林徽因，也在，同样的，政治压力下，郁郁而终。

但，梁思成的，预言，在，三十年后，应验了。1980年代，以后，越来越多的，人，开始，意识到，北京，失去的，东西，是，永远，找不回来的。北京，虽然是，新中国，的，首都，但它，已经，失去了，它，作为，世界最伟大古都之一，的，城市面貌。

**【年表层】**

| 时间 | 事件 |
|------|------|
| 1950年 | 梁思成提出「梁陈方案」，建议在西郊建设新行政中心，保护老城，被否决 |
| 1951年 | 北京市政府决定，利用旧城进行改造，不另建新城 |
| 1952年 | 北京开始拆除部分城墙和城门，用于城市建设 |
| 1953年 | 北京市制定「改建与扩建北京市规划草案」，正式确定在旧城基础上改造北京 |
| 1954年 | 长安街开始拓宽，沿线的牌楼被迁移或拆除 |
| 1956年 | 地安门拆除，这是中轴线上的一座重要建筑 |
| 1957年 | 梁思成在反右运动中被批判，被定为「右派分子」，他的保护方案被全面否定 |
| 1958年 | 为庆祝十周年国庆，北京进入城市改造高潮期，大量古建筑在此期间被拆除 |
| 1960年代 | 北京城墙和城门，大部分被完全拆除 |
| 1965年 | 北京地铁一号线开工，利用部分护城河和城墙地基修建 |
| 1966年 | 文革开始，大量幸存的古建筑，牌楼，寺庙，被红卫兵砸毁 |
| 1969年 | 北京城墙几乎被完全拆除，仅剩正阳门城楼，箭楼，和东南角楼等少量残余 |
| 1972年 | 梁思成在北京病逝，带着他没能实现的北京保护方案的遗憾 |

**北京·正阳门城楼和箭楼**

北京内城，唯一，完整保存的，城门，位于，天安门广场，南侧，正阳门城楼，和，箭楼，也是，梁思成，当年，极力，保护的，一部分，它们，是，北京，从，帝都，到，现代首都，的，沉默的，见证者

**北京·清华大学（梁思成纪念展）**

清华大学建筑学院，设有，梁思成纪念室，和，梁思成生平，与，学术成就，的，专题展览，包括，他在，北京城市保护中的，努力，和，他的，建筑学术，贡献，是，了解这位，「北京古城的，守护者」的，最好地点
