**【故事层】**

小悦，老刘头的曾孙女，2026年夏天，做了一件事，她的曾祖父、祖父和父亲，都不敢想象的事。

她沿着中国海岸线，从南到北，走了一趟。

从广州出发，到汕头，到福州，到泉州，到温州，到台州，到杭州，到上海，到连云港，到青岛，到天津，到秦皇岛，到大连。

十二座城市，三千多公里的海岸线，她用了两个星期，坐高铁，坐轮渡，坐公交，打的，也走了很多路。

在广州，她站在虎门的炮台前，看珠江入海。

在泉州，她去了妈祖庙，看到了那些从宋元时期就开始使用的古码头。

在上海，她站在外滩，面对着浦东的天际线，看黄浦江，汇入长江，长江，汇入大海。

在青岛，她站在信号山上，看红瓦绿树，碧海蓝天，想起了这座城市，曾经是德国的殖民地。

在秦皇岛，她站在老龙头的城台上，看着长城，伸入大海。

在大连，她站在白玉山上，俯瞰旅顺港，想起了曾祖父老刘头，在这座山上，看到的，那些俄国军舰。

她把旅行的照片，发到社交媒体上，写了一句话：

「沿着海岸线走了三千公里，发现一个秘密：中国的历史，是陆地的，但中国的未来，是海洋的。」

这条动态收到了很多点赞。但小悦知道，她说的这个「秘密」，其实一点也不秘密，因为，这部课程的一百多章，都在讲这件事。

**【历史背景层】**

**十二座城市，十二个中国与海洋的故事**

这趟从广州到大连的海岸线旅程，十二座城市，每一座，都代表了中国与海洋之间，一种不同的关系。

| 城市 | 核心主题 | 中国与海洋的关系 |
|------|---------|----------------|
| 广州 | 鸦片战争 · 海防失败 | 海，是威胁的来处 |
| 汕头 | 移民 · 红头船 | 海，是逃生的路 |
| 福州 | 马尾船政 · 海军梦 | 海，是现代化的课堂 |
| 泉州 | 海上丝绸之路 | 海，是千年贸易的大道 |
| 温州 | 民间经济 · 出海 | 海，是草根的生存空间 |
| 台州 | 倭寇 · 海盗 | 海，是秩序的破坏者 |
| 杭州 | 南宋 · 海洋朝廷 | 海，是偏安的屏障 |
| 上海 | 租界 · 全球化 | 海，是通往世界的窗口 |
| 连云港 | 铁路 · 欧亚大陆桥 | 海，是陆地的延伸 |
| 青岛 | 殖民城市规划 | 海，是帝国竞赛的舞台 |
| 天津 | 北洋 · 北京的门户 | 海，是权力中心的外围 |
| 秦皇岛 | 长城入海 · 防御的终点 | 海，是墙的尽头 |
| 大连 | 三国占领 · 殖民之殇 | 海，是被争夺的对象 |

把这些城市，连成一条海岸线，我们看到了什么？

我们看到了，中国与海洋的关系，不是单一的，而是一百种，甚至一千种，不同的面貌。对于广州的渔民，海是家，对于泉州的商人，海是路，对于上海的银行家，海是一张通往世界的门票，对于旅顺的士兵，海是前线，对于北戴河的领导人，海是度假，对于搬砖的老刘头，海，是他每天搬运的石头，被装上了船，运往他不知道的地方。

中国，不是一个「海洋民族」，也不是一个「陆地民族」，它是一个，在陆地与海洋之间，反复摇摆、反复选择、反复后悔、反复重新出发的，国家。

**海岸线，不只是边界**

我们通常，把海岸线理解为「边界」，陆地的终点，海洋的起点。

但这趟旅程告诉我们，海岸线，不是一条线，而是一个区域，是陆地与海洋相互碰撞、相互渗透、相互塑造的，过渡地带。在海岸线上，泥沙从陆地流入海洋，形成了三角洲，海风从海洋吹向陆地，改变了气候，人在海岸线上，建港口，筑城墙，修铁路，盖城市，每一次，都既改变了陆地，也改变了海洋。

海岸线，是动态的，不是固定的，是变化的，不是静止的，是活的，不是死的。

中国的海岸线，一万八千公里，从北到南，跨越了寒温带、温带、亚热带和热带，其多样的自然环境，孕育了同样多样的，人与海的关系。这，就是为什么，沿着海岸线走，能比沿着长江走，或者沿着长城走，看到更多元的中国。

**【深挖层】**

**一个从未真正「面对海洋」的文明**

中国，通常被认为是一个「大陆文明」，以农立国，以陆地为根基，以长城为屏障，以中原为核心。这个描述，大体上是正确的，但，在它的边缘，在那些被中原王朝忽略的沿海角落，中国，也拥有一套，同样古老、同样丰富、同样深刻的，海洋传统。

只是，这套传统，在官方历史书写中，长期被忽略，被压缩，被遗忘。

从秦朝到清朝，历代中国王朝的政策，都以「重陆轻海」为主旋律。海上贸易，时开时禁，海外移民，被视为「叛离」，海军，往往只是陆军的一个附属兵种，海洋技术，尽管曾经领先世界，却在近代，被远远甩在后面。

这种「重陆轻海」的传统，造成了中国近代史上最惨痛的失败：当威胁从海上而来时，中国，没有准备好。

但这趟旅程，也让我们看到了，在官方政策的「重陆轻海」之外，中国的沿海，一直存在着一股，民间的、自发的、持续不断的，面向海洋的力量。福建的商船，在宋元时期，就已经穿行于南海和印度洋之间。广东的移民，在明清时期，就已经到达东南亚的每一个角落。浙江的渔民，世世代代，在风浪中讨生活。这些力量，虽然被朝廷压制，被史书忽略，但它们，从未消失。

中国，不是没有海洋基因，而是，它的海洋基因，在一个「重陆轻海」的文明框架中，被压抑了一千多年。

**沿着海岸线，回到未来**

这部课程，沿着中国海岸线走了一趟，十二座城市，一百多章，从鸦片战争，到大连的万亿GDP，从红头船，到航空母舰。

我们看到了，中国与海洋的关系，经历过的最深的低谷，也看到了，它正在进入的，可能最广阔的上升期。

在广州，我们看到了海防的失败，也看到了改革开放的前沿。

在泉州，我们看到了海上丝绸之路的繁华，也看到了它被时代抛弃后的沉寂。

在上海，我们看到了租界的屈辱，也看到了全球城市的崛起。

在大连，我们看到了三个帝国的反复占领，也看到了，一座殖民城市，如何在一百年后，变成了，完全属于自己的家。

中国的海岸线，从来不只是一个地理概念，它是一面镜子，映照着中国，从一个传统帝国，走向现代国家，的全部历程。

**【思考层】**

「我们沿着海岸线，看见了什么？」

这是大连市终章的标题，也是整个课程，从第一章开始就想问的问题。

我们看到的，是一部中国与海洋之间，从疏离，到被迫，到主动，到全面拥抱，的漫长历史。

我们看到了，一个在陆地上有着五千年文明史的古老国家，在面对海洋时，的那种迟疑、恐惧、笨拙和冒险，以及，最终，的勇气和智慧。

我们看到了，那些在海岸线上生活的人，他们，比任何帝王和大臣，都更早地理解了大海的意义，他们，在朝廷还在纠结开放还是禁海的时候，已经划着船，出海去了。

我们看到了，长城和港口，在同一片海岸线上，相距不过二十公里，代表着两种完全不同的文明态度，一个向内，一个向外，一个守护，一个连接，而后者，最终，胜出了。

这，也许就是沿着海岸线走这一趟，最大的收获：中国的未来，不在长城之内，而在，海岸线之外。

那里，是出发的地方。

**【旅行层】**

**如何走一趟中国海岸线**

如果你想自己走一趟这条海岸线，以下是建议路线：

- **起点**：广州（虎门炮台 · 沙面 · 黄埔古港）
- **北上**：汕头（红头船公园 · 老市区）→ 福州（马尾船政博物馆）→ 泉州（海外交通史博物馆 · 妈祖庙）
- **东进**：温州 → 台州 → 杭州（南宋官窑博物馆）
- **上海**：外滩 · 上海历史博物馆
- **继续北上**：连云港 → 青岛（信号山 · 德国总督楼）→ 天津（五大道 · 大沽炮台）
- **最后两站**：秦皇岛（山海关 · 老龙头）→ **终点**：大连（中山广场 · 旅顺 · 白玉山）

全程建议用时：三到四周。最佳季节：春秋两季（避开南方的台风季和北方的严冬）。

**不用一次走完**

如果你没有时间一次走完，也没有关系。

中国，是一个海岸线非常，非常，非常，长的国家。你可以从你所在的城市，向着大海的方向，走几步，走到海边，站在那里，想一想，脚下的这片海，都见过什么。

这就是，这门课程，最想教给你的东西。

**【推荐读物】**

1. 《中国海洋文明史》，关于中国海洋文明从先秦到当代发展历程的通史性著作，是理解中国与海洋关系的系统参考
2. 《海上丝绸之路》，关于中国古代海上贸易路线的历史，从广州、泉州出发的航线，到达东南亚、印度、阿拉伯和东非
3. 《中国近代海防史》，关于中国近代海防思想的演变和海防体系的建设，从鸦片战争到新中国成立，是中国与海岸线关系的核心叙事之一
4. 《沿着海岸线，中国沿海城市的历史与未来》，以游记形式，串联中国沿海城市的历史和现状，是这趟旅程的延伸阅读
5. 《山海经》（远古篇），一切中国地理的起点，包括对海岸线的最早描述，读这本书，就是从中华文明的最深处，重新理解中国与山海的关系
